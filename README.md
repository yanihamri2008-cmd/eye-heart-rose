# Eye - Heart - Broken - Rose

Animated terminal story in pure Python, no libraries:
a moving eye, zoom into the pupil, a beating heart, the heart breaks, a wilted rose.

By SONICTEAM

## Run

    pkg install python git -y
    git clone https://github.com/USERNAME/eye-heart-rose.git
    cd eye-heart-rose
    python eye_heart_rose_v2.py

## Tips

- Zoom the terminal font out (pinch in Termux) for more detail.
- Needs a truecolor terminal.
- Press Ctrl+C to stop.
